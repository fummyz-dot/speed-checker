# Horse visual reference

This directory contains design-reference assets for the Speed Checker race visualization.

## horse-reference-user.png

Purpose: visual reference for the user-lane racehorse.

This is **not** a production runtime asset by default. Do not import it into the application bundle unless a later task explicitly decides to use raster assets in production.

Key visual characteristics to preserve when implementing the lightweight web version:

- unmistakable racehorse proportions at small size;
- long horse-shaped head and muzzle;
- long neck connected naturally to the shoulder;
- large horizontal barrel/torso;
- long, thin legs with clear hooves;
- strong hindquarters;
- flowing mane and tail;
- forward-leaning jockey;
- natural brown horse body;
- teal used on jockey silks / saddle cloth / accents, not on the horse body itself;
- recognizable side-profile silhouette before animation is added.

Do not copy the image pixel-for-pixel into SVG. Use it as the approved shape, proportion, color, and pose reference.
